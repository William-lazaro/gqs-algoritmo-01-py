## **Sobre o projeto**

Este projeto foi desenvolvido em Python, com o intuito de descobrir se uma palavra ou frase é um **Palíndromo**.
<p>Um <b>Palíndromo</b> é um texto que, sem o uso de espaço, pontuações e diferença entre letras maiúsculas e minúsculas pode ser lido de qualquer maneira, da direita pra esquerda ou vice-versa.<p/>
