## **Sobre o projeto**

Este projeto foi desenvolvido em Python, com o intuito de descobrir se uma palavra ou frase é um **Palíndromo**.
<p>Um <b>Palíndromo</b> é um texto que, sem o uso de espaço, pontuações e diferença entre letras maiúsculas e minúsculas pode ser lido de qualquer maneira, da direita pra esquerda ou vice-versa.<p/>

# **Desvendando os métodos:** 

<p>Ele define o ponto de início da execução do programa. Nesse bloco, você coloca os documentos que devem ser executados quando o arquivo Python é executado diretamente.</p>

<p> O método analisar(entrada) receber uma corda como metro e verifica se ela é um palíndromo, ou seja, se pode ser lida da mesma forma da esquerda para a direita e da direita para a esquerda, desconsiderando espaços, pontução e diferenças entre letras maiúsculas e minúsculas.</p>
